🏀 Basketball Scoreboard App

A simple and interactive basketball scoreboard web app that allows users to keep track of scores for two teams in real-time.

🚀 Features
Add points (1, 2, or 3) for both teams
Real-time score updates
Clean and minimal UI
Reset scores functionality
Easy to use and beginner-friendly
🛠️ Tech Stack
HTML
CSS
JavaScript
📂 Project Structure
basketball-scoreboard/
│── index.html
│── style.css
│── script.js
🎮 How It Works
Click buttons to add points to the Home or Guest team
Scores update instantly on the screen
Use the reset button to restart the game
▶️ Getting Started
Clone the repository
git clone https://github.com/your-username/basketball-scoreboard.git
Open the project folder
Run index.html in your browser
